## Selected projects

### WildTrack Live
[Source code](https://github.com/Harleynoble16/WildTrackLive)  
Python · Streamlit · pandas · requests · Folium

- Built an interactive application that retrieves animal and GPS records from a Movebank study and maps recent lesser kestrel tracking data.
- Processed timestamps and grouped records to identify each bird's latest recorded position, with a selectable route showing up to 500 recent points.
- Added request timeouts, one-hour response caching and messages for network failures and rate limits.
- Kept credentials in Streamlit secrets and documented that published tracking records are not guaranteed real-time positions.

### Live Wildlife Monitor
[Source code](https://github.com/Harleynoble16/LiveWildlifeApp) · [Live application](https://live-wildlife-monitor.streamlit.app/)  
Python · Streamlit · SQLite · pandas

- Developed a wildlife-viewing interface with a selector for 16 embedded camera feeds and source attribution.
- Implemented sighting entry for species, animal count and notes, validating that a species name is provided before saving.
- Used parameterised SQL to store observations in a local SQLite database and retrieve them in newest-first order.
- Added a sightings table and CSV export. Local storage persists between runs when the database file is retained; cloud-hosted local files are not a guaranteed durable store.

### UK Wildlife Data Project
[Source code and charts](https://github.com/Harleynoble16/WildlifeProject)  
Python · pandas · Matplotlib

- Analysed historical JNCC qualifying bird records for UK Ramsar wetland sites.
- Converted count strings to numeric values, inspected missing data and separated assemblage records from individual-species records.
- Produced charts comparing the largest individual bird records, sites by distinct qualifying species and site coordinates.
- Documented the distinction between historical qualifying records, current populations and total site biodiversity.
